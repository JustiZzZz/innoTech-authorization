# Тестовое задание InnoTech Solutions

Сервис регистрации и авторизации пользователей по ссылке на email.

Стек: Python 3.12, FastAPI, PostgreSQL, SQLAlchemy 2 (asyncpg), Alembic, Docker Compose. Для перехвата писем локально используется Mailpit (чтобы вам не нужно было возиться с реальными SMTP-паролями).

## Как запустить

Всё завернуто в докер, поднимается одной командой:

docker compose up --build

При старте контейнер сам накатит миграции Alembic и запустит uvicorn на 8000 порту.

## Где что смотреть

- http://localhost:8000 — веб-морда с формой регистрации и входа
- http://localhost:8025 — веб-интерфейс Mailpit (сюда падают все письма со ссылками активации)
- http://localhost:8000/docs — Swagger документация API

## Как протестить флоу

1. Открываете http://localhost:8000
2. Вводите email и пароль (от 8 символов), жмете "Зарегистрироваться"
3. Переходите в Mailpit на http://localhost:8025 — там сразу появится входящее письмо
4. Кликаете в письме по кнопке "Подтвердить Email"
5. Откроется страница успешного входа: аккаунт активирован, выдан рабочий JWT access token
6. Теперь можно вернуться на http://localhost:8000, переключиться на вкладку "Вход" и залогиниться по паролю

Также эндпоинт верификации сделан гибридным: если перейти по нему из браузера (Accept: text/html), он отдает страницу успеха, а если дергать через Swagger или curl — возвращает JSON с токеном.

## Про использование нейронки (честно, как есть)

В описании задачи было написано про вайбкодинг, поэтому расписываю честно границы ответственности:

- Что делала нейронка:
  1. Сверстала простой HTML/CSS для шаблонов (форма регистрации и страница подтверждения), чтобы я не тратил на это время.
  2. На старте помогла набросать структуру базовых таблиц под SQLAlchemy 2.
  3. Помогла аккуратно сформулировать комментарии и докстринги в коде по моим указаниям.

- Что делал я сам:
  1. Архитектуру и структуру модулей (core, models, repositories, services, api v1).
  2. Всю бизнес-логику: флоу подтверждения, работу с транзакциями, доменные исключения.
  3. Безопасность: хеширование Argon2id, выпуск JWT, паттерн Hash-at-Rest для одноразовых ссылок (в базе только sha256 хеш токена, сырой токен только в ссылке).
  4. Защиту от повторных кликов (replay attack) через used_at и проверку TTL.
  5. Настройку асинхронной базы (asyncpg, pool_pre_ping, expire_on_commit), настройку асинхронного env.py для Alembic.
  6. Настройку Dockerfile (запуск из-под non-root пользователя appuser) и docker-compose со связкой healthcheck для базы и локальным Mailpit.
  7. Дебаг и отладку всех возникающих ошибок при запуске.
